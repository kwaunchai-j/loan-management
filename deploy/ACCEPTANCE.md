## D. เวลาแจ้งเตือนตามเวลาไทย (ต้องรอเวลาจริง)

เตรียมข้อมูล **วันก่อนหน้า**: สัญญาที่ครบกำหนด **พรุ่งนี้** 1 สัญญา (ยังไม่ชำระ) และสัญญาที่ครบกำหนดแล้ว **เมื่อวานหรือก่อนหน้า** อีก 1 สัญญา (ยังไม่ชำระ)

| # | เวลา (ไทย) | ผลที่ควรเห็น | ผล | เวลาที่ได้รับจริง |
|---|---|---|---|---|
| D1 | 00:05 | ค่าปรับของสัญญาที่เลยกำหนดเพิ่มขึ้นหนึ่งวัน (ดูรายละเอียดสัญญา > ค่าปรับรายวัน) | ☐ | |
| D2 | 09:00 | แจ้ง "วันนี้ครบกำหนดชำระ N สัญญา" (รวมยอด) ทั้ง LINE และ Web Push — **ฉบับเดียว** | ☐ | |
| D3 | 17:00 | แจ้ง "เลยกำหนดชำระ N สัญญา" (ฉบับเดียว สรุปทั้งหมด) | ☐ | |
| D4 | วันถัดไป 17:00 (สัญญายังไม่ชำระ) | แจ้งเลยกำหนดอีกครั้ง (ส่งทุกวันจนชำระครบ) | ☐ | |
| D5 | รีสตาร์ท api ช่วงบ่าย: `compose restart api` | **ไม่มี** แจ้งเตือนซ้ำของรอบเดิม | ☐ | |

## E. ลำดับ end-to-end (คำขอ → อนุมัติ → จ่ายเงิน → ชำระ → ปิดสัญญา)

ใช้ข้อมูลทดสอบ (ผู้ยืมสมมติ) — จดเลขสัญญาและตัวเลขที่เห็นไว้เทียบกับที่คำนวณด้วยมือ

| # | ขั้นตอน | ผลที่ควรเห็น | ผล | หมายเหตุ |
|---|---|---|---|---|
| E1 | แอดมินสร้างผู้ยืม (ชื่อ เบอร์ ธนาคาร เลขบัญชี) | แสดงรหัสผ่านชั่วคราวครั้งเดียว | ☐ | |
| E2 | ผู้ยืมเข้าสู่ระบบบนมือถือ | บังคับเปลี่ยนรหัสผ่าน → หน้าเงื่อนไข PDPA → หน้าหลัก | ☐ | |
| E3 | ผู้ยืมส่งคำขอ (จำนวนเงิน + วันที่คืน) | สถานะ "รอพิจารณา"; แอดมินได้แจ้งเตือนทันที | ☐ | |
| E4 | แอดมินอนุมัติ | สัญญา "รอจ่ายเงิน"; ผู้ยืมเห็นสัญญาแต่ **ไม่เห็นยอดที่ต้องชำระ** | ☐ | |
| E5 | แอดมินบันทึกจ่ายเงิน (แนบสลิปจากมือถือ/ภาพจริง) | ได้ดอกเบี้ยตามสูตร (เงินต้น × อัตรา% × วัน ÷ 30 ปัดขึ้น); ผู้ยืมเห็นยอดที่ต้องชำระ | ☐ | ยอดที่คำนวณมือ: ____ ระบบ: ____ |
| E6 | แอดมินกดดูสลิป | เห็นภาพสลิป; ผู้ยืมเปิดสลิปไม่ได้ (ลองเปิดลิงก์ในบัญชีผู้ยืม ต้องไม่ผ่าน) | ☐ | |
| E7 | บันทึกรับชำระบางส่วน ("จ่ายเพื่อลดยอดรวมที่ติด") | ตัดค่าปรับ → ดอกเบี้ย → เงินต้น ตามลำดับ; ยอดคงเหลือถูก | ☐ | |
| E8 | ลองจ่ายเกินยอด | ถูกปฏิเสธด้วยข้อความไทย | ☐ | |
| E9 | บันทึกชำระครบ | สัญญา "ชำระครบแล้ว" ผู้ยืมเห็นประวัติ | ☐ | |
| E10 | แก้ไข/ลบรายการรับชำระ | มีคำเตือนผลต่อรายงาน/การแจ้งเตือน; ยอดคำนวณใหม่; สัญญาที่ปิดอาจเปิดกลับ | ☐ | |
| E11 | รายงานทั้ง 4 (เดือนนี้/ปีนี้/ช่วงวัน) | ตัวเลขตรงกับที่ทำมือจากรายการจริง | ☐ | |
| E12 | นำเข้าไฟล์ **Excel จริง** (.xlsx) จากผู้ให้กู้ | ตรวจไฟล์ได้ (ภาษาไทยไม่เพี้ยน), ชื่อซ้ำให้เลือก, ค่าปรับย้อนหลังตรงที่คาด, ย้อนกลับได้ | ☐ | ไฟล์จริงเปิดได้ไหม? |
